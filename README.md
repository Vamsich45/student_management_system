#  Student Management System (Python Project)

Hi!   
This is a simple **Student Management System** built using Python.  
I created this project to practice **Object-Oriented Programming (OOP)** and improve my Python basics.

---

##  What this project does

This system helps you manage student records easily. You can:

- Add student details (name, roll number, marks)
- View all students with their results
- Search a student using roll number
- Automatically calculate:
  - Total marks
  - Percentage
  - Pass/Fail result

---

##  Concepts used

While building this project, I learned and used:

- Classes and Objects (OOP)
- Constructors (`__init__`)
- Methods and functions
- Lists in Python
- Loops and conditions
- User input handling
- Basic program structure (menu-driven system)

---

##  How to run

Just follow these simple steps:

1. Make sure Python is installed on your system
2. Download or clone this project
3. Open terminal in the project folder
4. Run the file:

bash / terminal
      python student_management_system.py
